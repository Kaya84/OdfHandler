# OdfHandler

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

An elegant, lightweight, and high-performance thumbnail handler for **MediaWiki (1.40+)** to automatically generate preview images for OpenDocumentFormat files (`.odt`, `.ods`, `.odp`).

---

## 🇬🇧 English Documentation

### ✨ Key Features
* 🚀 **Zero Overhead:** Does **not** require LibreOffice, OpenOffice, or heavy external tools (like `unoconv`) installed on the server. Instead, it extracts the pre-rendered PNG preview (`Thumbnails/thumbnail.png`) that office suites natively embed inside the ODF zip archive upon saving.
* 🧠 **RAM-only Processing:** Image resizing happens entirely in RAM using PHP's GD library. No heavy system processes are spawned.
* 🛡️ **`FileBackend` Native Compatibility:** Correctly interfaces with MediaWiki's storage abstraction layer (`mwstore://`), working flawlessly on both local setups and distributed cloud environments (e.g., AWS S3).
* 🔄 **Intelligent Fallback:** If an ODF file is generated by automated third-party software/scripts and lacks an internal preview, the extension automatically loads a format-specific fallback icon, preventing `0x0` database errors or page crashes.

### 📋 Requirements
* **MediaWiki:** 1.40 or higher (Tested on **MediaWiki 1.43.x**)
* **PHP:** 8.0 or higher
* **PHP Extensions:** `php-zip` and `php-gd`

### 🛠️ Directory Structure
Place the extension inside your `extensions/` directory with the following structure:

```text
OdfHandler/
├── extension.json
├── src/
│   └── OdtHandler.php
└── resources/
    ├── default-odt.png
    └── default-ods.png
```

### 📦 Installation

1. Enable the extension by adding the following line at the bottom of your **`LocalSettings.php`** file:
   ```php
   wfLoadExtension( 'OdfHandler' );
   ```

2. *(Optional)* If your wiki already has existing `.odt`, `.ods`, or `.odp` files uploaded before installing this extension, you may need to force MediaWiki to recalculate their metadata and thumbnails. Run the following maintenance commands from your server's terminal:
   ```bash
   php maintenance/refreshImageMetadata.php --mime application/vnd.oasis.opendocument.text --force
   php maintenance/refreshImageMetadata.php --mime application/vnd.oasis.opendocument.spreadsheet --force
   php maintenance/refreshImageMetadata.php --mime application/vnd.oasis.opendocument.presentation --force
   ```

### 🎨 UI Optimization
To hide the unnecessary *"No higher resolution available"* message on document file pages, add this snippet to your wiki's **`MediaWiki:Common.css`** page via your browser:

```css
body.filetype-odt .mw-filepage-nohires,
body.filetype-ods .mw-filepage-nohires,
body.filetype-odt #mw-imagepage-nofullhighres, 
body.filetype-ods #mw-imagepage-nofullhighres {
    display: none !important;
}
```

## 🇮🇹 Documentazione in Italiano

### ✨ Caratteristiche principali
* 🚀 **Zero Overhead:** **Non richiede** l'installazione di LibreOffice, OpenOffice o strumenti esterni pesanti (come `unoconv`) sul server. Scompatta al volo l'archivio del documento ed estrae l'immagine PNG pre-renderizzata (`Thumbnails/thumbnail.png`) che la suite da ufficio genera nativamente al momento del salvataggio.
* 🧠 **Elaborazione in RAM:** Il ridimensionamento delle immagini avviene interamente nella memoria RAM tramite la libreria GD di PHP. Nessun processo di sistema pesante viene avviato sul server.
* 🛡️ **Compatibilità nativa `FileBackend`:** Dialoga correttamente con il livello di astrazione dei file di MediaWiki (`mwstore://`), funzionando alla perfezione sia su server locali sia in ambienti cloud distribuiti (es. AWS S3).
* 🔄 **Fallback Intelligente:** Se un file ODF viene generato da un software terzo o da un gestionale automatico e risulta privo di anteprima interna, l'estensione carica automaticamente un'icona di riserva specifica per il formato, evitando errori `0x0` o crash della pagina.

### 📋 Requisiti
* **MediaWiki:** Versione 1.40 o superiore (Testato con successo su **MediaWiki 1.43.x**)
* **PHP:** Versione 8.0 o superiore
* **Estensioni PHP richieste:** `php-zip` e `php-gd`

### 📦 Installazione

1. Abilita l'estensione aggiungendo la seguente riga in fondo al tuo file **`LocalSettings.php`**:
   ```php
   wfLoadExtension( 'OdfHandler' );
   ```

2. *(Opzionale)* Se nel tuo wiki sono già presenti file caricati in precedenza e hai bisogno di rigenerare le miniature o correggere eventuali errori, esegui questi script di manutenzione da terminale per i vari formati:
   ```bash
   php maintenance/refreshImageMetadata.php --mime application/vnd.oasis.opendocument.text --force
   php maintenance/refreshImageMetadata.php --mime application/vnd.oasis.opendocument.spreadsheet --force
   php maintenance/refreshImageMetadata.php --mime application/vnd.oasis.opendocument.presentation --force
   ```

### 🎨 Ottimizzazione dell'Interfaccia
Per nascondere il messaggio *"Non sono disponibili versioni a risoluzione più elevata"* dalle pagine dei documenti, aggiungi questo codice alla pagina **`MediaWiki:Common.css`** del tuo wiki direttamente dal browser:

```css
body.filetype-odt .mw-filepage-nohires,
body.filetype-ods .mw-filepage-nohires,
body.filetype-odt #mw-imagepage-nofullhighres, 
body.filetype-ods #mw-imagepage-nofullhighres {
    display: none !important;
}
```
